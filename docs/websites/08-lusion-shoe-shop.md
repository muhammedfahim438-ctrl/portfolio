# Lusion - Shoe Shop Demo

**URL:** https://lusion.arrowtheme.com/demo-shoe-shop/
**Theme/Demo:** Lusion (Home Shoe Shop) by ArrowTheme / ThimPress

---

## 📌 What This Site Is About
A **demo of the "Home Shoe Shop"** layout of the **Lusion WordPress theme** — a **multipurpose e-commerce template** showcasing a **premium sneaker/shoe store** featuring Nike Air Max, Adidas, RS-X, and dress shoes. Functions as both a usable storefront mock-up and a sales page for the theme itself.

---

## 🛠️ Tools Used
- **WordPress** (CMS) — theme version `FOX v.1.4.9`
- **WooCommerce** (e-commerce)
- **Lusion Theme** by **ArrowTheme / ThimPress**
- **WPML** (multilingual: English / French / German)
- **WooCommerce Currency Switcher** (USD/EUR)
- **WPBakery / Visual Composer**

## 🎨 Animations Used
- **GSAP** (scroll and entrance animations — Lusion's signature)
- **Swiper.js / Slick Slider** (product carousels, hero slider)
- **Isotope / Masonry** (product grids)
- **Magnific Popup / Lightbox** (quick view modals)
- **Countdown / Notification widgets** (recent-purchase popups)
- **Smooth scroll-triggered animations and parallax effects**
- **Hover-driven product cards** (quick-view, wishlist, compare actions)
- **"Sold out" badges and pricing emphasis**

## 📦 Packages Used (WordPress Plugins)
- WooCommerce
- WPML
- WooCommerce Currency Switcher
- WPBakery / Visual Composer
- Revolution Slider
- Instagram Feed plugin
- Lusion theme-required plugins

## 📚 Libraries Used
- **jQuery** (core)
- **Font Awesome / Ionicons** (Lusion default)
- **Instagram embed** (instagram.com/p/...)

## 🎨 Design Style
- **Modern premium e-commerce aesthetic**
- **Minimalist** with bold typography and generous whitespace
- **Editorial / fashion-magazine** feel (overlapping text, large product imagery, asymmetric grids)
- Smooth scroll-triggered animations and parallax effects

## 🎨 Color Palette
- **Black / Off-white** base (high-contrast fashion palette)
