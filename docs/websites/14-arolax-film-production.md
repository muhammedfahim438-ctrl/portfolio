# Arolax - Film Production Agency Demo

**URL:** https://arolax.crowdytheme-demo.com/film-production-agency/
**Theme/Demo:** Arolax (Film Production Agency dark variant) by CrowdyTheme

---

## 📌 What This Site Is About
A **demo template for a Film Production / Movie Studio agency** (part of the multi-purpose **Arolax WordPress theme** by CrowdyTheme). The dark-variant landing page positions a fictional filmmaker "FARMUSE" as an "Awarded creative filmmaker," showcasing awards, recent film releases, crew members, and film festival events.

---

## 🛠️ Tools Used
- **WordPress** (CMS)
- **Arolax Theme** by **CrowdyTheme** (ThemeForest)
- **Elementor** (primary page builder)
- **WooCommerce-ready** (Shop link present)
- **RTL-ready**

## 🎨 Animations Used
- **GSAP (GreenSock)** — scroll-triggered reveals (fade, slide, parallax)
- **Locomotive Scroll** — smooth/inertial scrolling
- **Three.js** — 3D/WebGL hero effects
- **Swiper** — carousels for films and events
- **Marquee/ticker** scrolling text and logos (animated CSS)
- **Cursor effects** and hover micro-interactions
- **Letter-by-letter text reveals** (Splitting.js / SplitType)
- **Masonry / Isotope** (portfolio filtering)
