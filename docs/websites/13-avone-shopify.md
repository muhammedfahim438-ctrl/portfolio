# Avone - Multipurpose Shopify Theme

**URL:** https://avone-demo.myshopify.com/
**Theme/Demo:** Avone by AdornThemes

---

## 📌 What This Site Is About
**Avone** is a premium **multipurpose Shopify theme** by **AdornThemes** — marketed as *"Fast, Flexible & Powerful Shopify Theme"*. The demo primarily showcases **fashion/clothing**, but the theme supports many niches (furniture, decor, jewelry, skincare, pet, grocery, yoga, autoparts, etc.).

---

## 🛠️ Tools Used
- **Shopify** (e-commerce platform)
- **Liquid templates** (Shopify's templating engine — confirmed via `Liquid error` message)
- **Avone theme** by **AdornThemes**

## 🎨 Animations Used
- **AJAX cart drawer** (slide-out)
- **MegaMenu** with smooth dropdown animations
- **Ajax Load More / Infinite Scroll** (product grids)
- **Quick View** modal popups
- **Wishlist** animations (heart icon fill)
- **Variant swatches** (color/image/select — animated hover)
- **Product 3D/AR models** (Shopify's native)
- **Countdown timer** (sale urgency)
- **Sticky Add-to-Cart** on scroll
- **Back-in-Stock** notifications
- **"Recently purchased" popup** (social proof)
- **Hover image-swap** on product cards
- **Smooth drawer animations**

## 📦 Packages Used (Shopify Integrations)
- Klaviyo (email marketing)
- Judge.me / Yotpo / Loox (product reviews)
- Bold Product Options / Infinite Options
- Shopify Subscriptions (for subscription products)
- Instafeed (Instagram shoppable gallery)
- Wishlist Plus / Swell
- Currency converter apps
- Searchanise / Smart Search
- PageFly / GemPages (page builder — optional)

## 📚 Libraries Used
- **Shopify CDN** (`cdn.shopify.com`)
- **Google Fonts** (Poppins / similar sans-serif typical)
- **Font Awesome** or **Ionicons** (icons)
- **Shopify's native 3D/AR viewer**
