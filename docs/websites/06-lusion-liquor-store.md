# Lusion - Liquor Store Demo

**URL:** https://lusion.arrowtheme.com/demo-liquor-store/
**Theme/Demo:** Lusion (Home Liquor Store) by ArrowTheme / ThimPress

---

## 📌 What This Site Is About
A **demo liquor/wine e-commerce storefront** built on the **Lusion multipurpose WordPress theme** by ArrowTheme (sold via ThimPress). Sells **liquor, wine, beer, and bar accessories** — showcasing brands like Hennessy, Rémy Martin, Jack Daniel's, Belasco, Camus, Absolut, Bacardi, Chivas, Moët Chandon, etc.

## 🛠️ Tools Used
- **WordPress** (CMS)

## 🎨 Animations Used
- **GSAP (GreenSock)** — scroll/entry animations, parallax
- **ScrollTrigger / ScrollMagic** — reveal-on-scroll
- **Lenis** — smooth scroll
- **Swiper.js / Slick** — product carousels and sliders
- **Isotope / Masonry** — product/portfolio grids
- **imagesLoaded** — grid layout completion
- **Magnific Popup / PrettyPhoto** — quick view & lightbox
- **CountUp.js** — animated counters
- **WOW.js + Animate.css** — entrance animations
- **Recent purchase notification popups** (conversion optimization)
- **Hover-reveal product cards**
