# Bazaro - Medical / Pharmacy HTML Template

**URL:** https://html.aqlova.com/bazaro-prev/bazaro/index-medical.html
**Theme/Demo:** Bazaro (Medical demo) by Themepure / Aqlova

---

## 📌 What This Site Is About
A **multi-purpose Bootstrap e-commerce template** (by **Themepure**) with a dedicated **medical/pharmacy homepage variant**. It's a healthcare & wellness online shop selling:
- OTC medicine, capsules, tablets
- Medical devices (BP monitors, oximeters, stethoscopes)
- Personal care, skincare, sexual wellness
- First aid, baby care, beauty care

The base template "Bazaro" supports **11 different store niches** (Fashion, Electronics, Cosmetics, Furniture, Medical, Cycle, Grocery, etc.).

- **WOW.js** — scroll-triggered entrance animations

- **Offcanvas** side panels (cart, wishlist, search)
